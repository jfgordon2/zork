# Scene artwork

[Scenery rules and acceptance checks](SCENERY_RULES.md) cover continuous access, human scale, connected geography, item supports, and the actual GBA crop. Follow these rules for new generations and edits.

The built-in ImageGen tool generated the room backgrounds. The checked-in PNGs are cropped and resampled to 240 × 102 for the GBA display. The renderer draws focus markers, portable items, and the open hatch over the backgrounds.

## Shared Boat Interior · `items/boat_interior.png`

This approved ImageGen foreground is used in every Zork I room while the player is aboard the inflatable boat. It supplies the consistent tube rim, a single interior slat, and the dark gray floor; carried cargo is drawn afterward so it remains visible above the floor. The 240×28 transparent sprite is anchored at `(0, 68)` and uses the same silhouette and placement across the river scenes.

## Zork I Grate States

Room 160 uses three matched backgrounds: `z1_grate_clearing_leaves.png` shows the leaves covering the grate, `z1_grate_clearing.png` shows its closed 4×4 grate, and `z1_grate_clearing_open.png` shows the opening with the grate panel laid flat on the far side. Room 216 uses `z1_grate_cellar.png` for the matching closed 4×4 grate and `z1_grate_cellar_open.png` for the open ceiling with the forest canopy visible above. The game selects these from the grate's open state and the leaves' visibility; the leaves pile is painted into the covered-clearing background to avoid drawing it twice.

Only production backgrounds belong at this directory's root. Retired comparisons stay in
`../docs/art-history/encounter-options/retired-backgrounds/`; the Z3 build list is explicit in the Makefile.
`encounter-options/imagegen-sprites/` is an active character-sprite build input; sibling
study and retired folders remain non-production.
